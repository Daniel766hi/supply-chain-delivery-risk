# Data

Put **`DataCoSupplyChainDataset.csv`** in this folder. The SQL load script expects exactly this path: `data/DataCoSupplyChainDataset.csv`.

1. Download from Kaggle (free account): https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis
   or from Mendeley Data: https://doi.org/10.17632/8gx2fvg2k6.5
2. Unzip and copy `DataCoSupplyChainDataset.csv` here (about 96 MB, 180,519 rows, Latin-1 encoded).

The CSV is git-ignored and is not redistributed in this repository.

**Source:** Constante, F., Silva, F., Pereira, A. (2019). *DataCo SMART SUPPLY CHAIN FOR BIG DATA ANALYSIS*. Mendeley Data, V5. doi:10.17632/8gx2fvg2k6.5. Licence: CC BY 4.0.
